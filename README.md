Czym jest ten projekt?
Jest to projekt zaliczeniowy z przedmiotu Podstawy Uczenia Maszynowego. 
Celem projektu było przewidzenie wyniku bitew historycznych (1600-1973) przy użyciu drzewa decyzyjnego.

## Co zawiera ten projekt?
- Integrację relacyjnej bazy danych (4 pliki CSV).
- Inżynierię cech (stworzenie wskaźnika `force_ratio`).
- Analizę problemu niezbalansowanych danych (Imbalanced Data).
- Test zderzeniowy modelu przy użyciu danych syntetycznych.
